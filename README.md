📊 Airbnb NYC – Power BI Dashboard

This project provides an interactive Power BI dashboard for analyzing Airbnb listings across New York City.
The dashboard highlights pricing trends, neighborhood patterns, availability, room types, and host behavior using clean visual storytelling.

📈 Key Dashboard Insights

⭐ Major Visuals

Price comparison across five NYC boroughs.

Room type distribution (Entire home, Private room, Shared room).

Host listing counts.

Availability across neighborhoods.

KPI cards (Avg Price, Total Listings, Availability%).

Interactive map of listings.

📌 Insights Discovered

Manhattan & Brooklyn have the highest prices and largest listing volume.

Entire homes dominate the premium price range.

Some hosts manage multiple listings, indicating commercial activity.

Availability shows clear variation by borough and room type.
